NodeCero Studio

Herramienta personal de producción y publicación de videos · Personal video production and publishing tool

¿Qué es?

NodeCero Studio es un programa de uso personal que corre en la computadora de su dueño. Sirve para preparar videos educativos y de sonido ambiente para los canales de YouTube de su propio dueño y, de forma opcional, para sus páginas de Facebook.

Usa la API de datos de YouTube (YouTube Data API v3) únicamente para:

  • subir videos, Shorts, miniaturas y subtítulos a los canales del propio dueño;
  • programar la fecha de publicación de esos videos y ordenarlos en listas de reproducción;
  • leer las estadísticas básicas de esos mismos canales para planear el contenido.

No es un servicio público: no tiene usuarios externos, no vende nada y no accede a cuentas de otras personas.

What is it?

NodeCero Studio is a personal desktop tool used only by its owner to upload, schedule and organize videos on the owner's own YouTube channels (and optionally the owner's Facebook pages) through the YouTube Data API v3. It has no external users and does not access anyone else's account.
